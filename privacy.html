개인정보처리방침

시행일 2026년 9월 22일

인벨(InBell, 이하 "인벨")은 이용자의 개인정보를 소중히 다루며, 이 방침으로 어떤 정보를 어디에 저장하고 언제 삭제하는지 알려 드립니다. 운영자는 안진우이며, 문의는 help@inbell.co.kr 로 받습니다.

1. 가입과 계정

인벨은 휴대폰 번호로 본인을 확인합니다.

가입 후 학원을 개설할 수 있으며, 학원 개설 후에는 앱 사용자를 해당 학원의 선생님·학부모·학생으로 초대할 수 있습니다.

2. 수집하는 개인정보 항목

인벨은 학원 업무 서비스(출결 알림, 공지, 상담, 학습 기록)를 제공하기 위해 아래 항목을 처리합니다.

구분항목
계정이름, 휴대폰 번호, 프로필 사진, 가입·최종접속 시각, 인증 식별자
학원학원명, 지점명, 소개 문구, 알림 설정
구성원역할(원장·선생님·학부모·학생), 상태, 학교, 학년, 보호자-학생 연결
출결날짜별 출결 상태, 등원·하원 시각, 지각·결석 예고(도착 예정 시각·사유·자유 입력), 지각 알림 발송 기록
학습숙제 미제출·불성실 기록과 메모, 수강 반과 기간, 개인 시간표, 보강·특강·휴강 일정과 메모
소통채팅 대화 내용·이미지, 공지 본문과 읽음 기록, 발송된 알림의 제목·본문·읽은 시각
기기푸시 알림 토큰, 기기 종류

3. 만 14세 미만 아동

학생이 만 14세 미만인 경우, 법정대리인의 동의를 받은 뒤 계정이 활성화됩니다.

4. 저장 위치

학원 데이터는 모두 Supabase 서울 리전(ap-northeast-2), 즉 국내에 저장됩니다.

5. 개인정보의 국외 이전

아래 두 가지 기능에 한해 구글(파이어베이스)로 정보가 이전됩니다.

이전받는 곳목적항목보유기간
구글(파이어베이스)휴대폰 인증휴대폰 번호회원 탈퇴 시까지(탈퇴 시 휴대폰 인증 계정 삭제)
구글(파이어베이스)푸시 알림알림 제목·본문알림 전달에만 사용

6. 보유와 파기

회원 탈퇴 시 삭제되는 것

  • 계정 정보(이름·휴대폰 번호·프로필 사진·이메일)
  • 프로필 사진 파일
  • 푸시 알림 토큰
  • 휴대폰 인증 계정

학원에 남는 것

출결·학습 기록은 학원에 남습니다. 이는 학원이 보관 의무를 지는 자료이며, 보관과 파기는 학원의 책임입니다.

학원이 보관하는 서류의 법정 기간(학원법 기준)

서류보관 기간
수강생대장3년
영수증5년
현금출납부5년

7. 이용자의 권리

이용자는 언제든지 자신의 개인정보에 대해 열람·정정·삭제·처리정지를 요청할 수 있습니다.

  • 앱 안 설정 → 개인 정보에서 직접 수정
  • 앱 안 설정 → 회원 탈퇴로 삭제
  • 또는 help@inbell.co.kr 로 요청

계정 삭제 방법은 계정 삭제 요청 페이지에서도 안내합니다.

8. 안전조치

  • 전송 구간 암호화(HTTPS)
  • 접근 권한 제한
  • 역할별 데이터 접근 통제

9. 개인정보 보호책임자

안진우 / help@inbell.co.kr

10. 방침의 변경

이 방침이 바뀌면 앱과 홈페이지에 공지합니다.
