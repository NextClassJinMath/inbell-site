출결

출발부터 도착까지,
알림이 먼저 와요

  1. 수업 전엔 아이 폰에 「출발할 시간이에요」
  2. 학원에 도착하면 보호자 폰에 등원 알림
  3. 안 오면 대화방에 「지각 발생」 빨간 카드
  4. 「지각 알리기」로 도착 시각만 답하면 끝
  5. 도착하면 초록 「등원」 카드

안 오면, 인벨이 먼저 물어요

간편 알림

지각·결석은
체크하고 누르면 끝

  1. 홈 「오늘 수업 알림」에서 아이를 체크
  2. 지각 · 결석 · 조퇴 중 하나를 눌러요
  3. 오늘 지각 — 도착 시각과 이유만
  4. 오늘 결석 — 빠지는 수업이 자동으로
  5. 며칠 빠질 땐 달력에서 미리 알리기

전화 없이, 버튼 하나로

달력

달력에서 한 번에

  2. 시작하는 날을 누르고, 끝나는 날을 골라요
  3. 보낸 날엔 꼬리표가 붙어요
  4. 학원 일정 막대와 아이 수업이 같이 보여요

  2. 등원 · 지각 · 결석 | 숙제 미제출 · 불성실 숫자
