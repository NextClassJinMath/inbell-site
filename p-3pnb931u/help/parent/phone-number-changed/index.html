휴대폰 번호를 바꿨어요

미리 구글 계정을 연결해 두면 새 번호로 기존 계정을 그대로 찾을 수 있어요.

  1. 번호를 바꾸기 전에 설정 › 「복구 계정 연결」을 눌러요.

  2. 「Google 계정」의 「연결」을 눌러 연결해 둬요.

  3. 새 번호 폰에서 인벨 첫 화면의 「기존 계정 찾기」를 눌러요.

  4. 「Google 계정으로 찾기」를 눌러 연결해 둔 계정을 골라요.

  5. 새 휴대폰 번호를 넣고 인증하면 기존 계정이 새 번호로 옮겨져요.

연결해 둔 계정이 없으면 원장님께 새 번호로 다시 초대를 요청해 주세요.
