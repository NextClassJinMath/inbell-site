지각하면 자동으로 연락이 가게 하고 싶어요

수업 시간이 지나도 등원 기록이 없으면 학생과 보호자에게 알림이 가고, 답이 없으면 원장님께 알려 드려요.

  1. 1학원 홈 「지각 자동 대응」 카드의 스위치로 켜고 멈출 수 있어요.

  2. 2스위치를 누르면 확인 창이 떠요. 한 번 더 고르면 바뀌어요.

  3. 3몇 분 늦으면 알릴지는 설정 → 학원 관리 → 「지각 자동 대응 설정」에서 골라요.

  4. 4학생마다 등하원 시간이 다르면 학생 상세의 「개별 등하원 시간」을 켜요.

  5. 5요일별 시간을 고르고 「저장」을 누르면 그 학생은 이 시간으로 지각을 판단해요.

「지각 자동 대응 설정」의 시간 칸은 누르는 순간 바로 바뀌어요. 학생별로 끄고 켜는 것도 학생 상세에서 할 수 있어요.

비슷한 상황

  • 학원 입구 태블릿으로 등하원을 찍고 싶어요태블릿을 키오스크로 켜 두면 학생이 출결번호 4자리를 눌러 직접 등원 · 하원을 찍어요.›
