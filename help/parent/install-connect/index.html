앱 설치하고 학원과 연결하기

학원에 알려 준 휴대폰 번호로 인벨을 시작하면 원장님이 보낸 초대장으로 학원과 바로 이어져요.

  1. 플레이 스토어(아이폰은 앱 스토어)에서 「인벨」을 찾아 설치해요.

  2. 인벨 앱을 열고 「휴대폰 번호로 시작하기」를 눌러요.

  3. 학원에 알려 준 휴대폰 번호를 넣고 「인증번호 받기」를 눌러요.

  4. 문자로 온 인증번호 6자리를 넣고, 처음이면 이름(실명)을 적어요.

  5. 첫 화면 「받은 초대」에 온 학원 초대장을 열고 아이 정보 이용에 동의하면 수락돼요.

  6. 수락한 학원이 첫 화면 목록에 생겨요. 눌러서 들어가요.

초대장이 안 보이면 원장님께 등록한 번호가 맞는지 물어봐 주세요.

비슷한 상황

  • 학원 알림이 안 와요인벨 알림 설정과 휴대폰 알림 설정을 차례로 확인하면 대부분 해결돼요.›
  • 아이 폰에도 인벨을 쓰게 하고 싶어요아이 폰에 인벨을 깔도록 알려 주고, 학원이 묻는 아이 정보 이용에 동의하면 아이도 쓸 수 있어요.›
  • 보호자 주소는 왜 적나요학원법 제15조의3에 따라 학원은 수강생 대장에 학생 주소를 적어 둬야 해요. 동·아파트까지만 적어도 돼요.›
