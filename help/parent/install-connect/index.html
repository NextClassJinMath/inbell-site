앱을 깔고 학원과 이어지고 싶어요

학원에 알려 준 휴대폰 번호로 인벨을 시작하면 원장님이 보낸 초대장으로 학원과 바로 이어져요.

  1. 1플레이 스토어(아이폰은 앱 스토어)에서 「인벨」을 찾아 설치해요.

  2. 2인벨 앱을 열고 「휴대폰 번호로 시작하기」를 눌러요.

  3. 3학원에 알려 준 휴대폰 번호를 넣고 「인증번호 받기」를 눌러요.

  4. 4문자로 온 인증번호 6자리를 넣고, 처음이면 이름(실명)을 적어요.

  5. 5첫 화면 「받은 초대」에 온 학원 초대장을 열고 아이 정보 이용에 동의하면 수락돼요.

  6. 6수락한 학원이 첫 화면 목록에 생겨요. 눌러서 들어가요.

초대장이 안 보이면 원장님께 등록한 번호가 맞는지 물어봐 주세요.
