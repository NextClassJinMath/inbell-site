학원 공지와 일정을 보고 싶어요

학원 홈 「일정」 카드와 아래 「공지」 탭에서 시험 · 특강 · 휴원 소식을 볼 수 있어요.

  1. 학원 홈 「일정 · 앞으로 2주」 카드에서 다가오는 일정을 바로 봐요.

  2. 아래 「공지」 탭을 눌러요.

  3. 「스케줄」 달력에서 날짜를 누르면 그날 일정과 아이 수업이 보여요.

  4. 「공지사항」을 누르면 학원 공지 전체를 볼 수 있어요.

새 공지가 올라오면 알림이 오고, 학원 홈 「읽지 않은 새 공지」에도 보여요.

  • 다른 날이나 며칠 동안 빠져요「지각·결석 예고」에서 달력의 날짜를 눌러 미리 알리면 여러 날도 한 번에 보낼 수 있어요.›
  • 선생님께 메시지 보내고 싶어요아래 「상담」 탭에서 아이 상담방을 열면 담당 선생님과 바로 이야기할 수 있어요.›
