학원에 와서 등원 · 하원을 찍고 싶어요

학원 입구 태블릿에 내 출결번호 4자리를 누르면 등원·하원이 보호자께 바로 알려져요.

  1. 1학원 입구 태블릿에서 「출결번호 4자리를 눌러주세요」 화면을 봐요.

  2. 2내 출결번호 4자리를 누르고 「출결」을 눌러요.

  3. 3내 이름이 맞는지 보고, 올 때는 「등원」, 갈 때는 「하원」을 눌러요.

「등원했어요」가 뜨면 끝이에요. 보호자께 알림이 가요. 번호를 잊었으면 선생님께 물어봐요.

비슷한 상황

  • 오늘 학원에 늦을 것 같아요공지 탭 달력의 「미리 알리기」로 늦는다고 학원에 바로 알릴 수 있어요.›
