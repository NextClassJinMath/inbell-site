앱을 깔고 보호자 허락을 받고 싶어요

학원에 등록한 내 휴대폰 번호로 시작하고, 보호자가 허락하면 학원과 바로 이어져요.

  1. 1스토어에서 「인벨」을 찾아 설치해요.

  2. 2앱을 열고 「휴대폰 번호로 시작하기」를 눌러요.

  3. 3학원에 알려 준 내 휴대폰 번호를 넣고, 문자로 온 인증번호를 넣어요.

  4. 4「보호자 동의를 기다리고 있어요」가 보이면 보호자께 앱에서 허락해 달라고 말해요.

  5. 5보호자가 허락하면 학원 초대장이 와요. 「수락」을 눌러요.

내 학원이 홈에 생겨요. 눌러서 들어가면 돼요. (만 14세 이상으로 등록됐다면 초대장의 「동의하고 시작」을 직접 누르면 돼요.)
