원장님 초대를 받아 학원에 들어가고 싶어요

원장님이 등록한 내 휴대폰 번호로 인벨을 시작하면 학원 초대장이 와 있어요. 수락하면 바로 학원과 이어져요.

  1. 1스토어에서 「인벨」 앱을 받아 설치해요.

  2. 2앱을 열고 「휴대폰 번호로 시작하기」를 눌러 원장님이 등록한 번호로 들어와요.

  3. 3첫 화면 「받은 초대」에 온 학원 초대장에서 「수락」을 눌러요.

  4. 4첫 화면에 학원이 생기면 눌러서 들어가요.

학원 홈에서 오늘 출결과 지각 상황을 바로 볼 수 있어요.
